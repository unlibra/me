# UI の見直し（13回目）：テーマカラーの整理とキャッチコピーの色（ユーザー承認、2026-10-23）

## ユーザーの指示

1. **色のトークンを整理する**（`src/styles/global.css`）
   - `logo-dark`（#1a7ba0）と `logo-accent`（#f88c49）を消す（どこでも使っていない。コメントの言及も直す）
   - `logo-light` → `primary-light`、`logo-medium` → `primary` に名前を変える。`card-link` → `link` に名前を変える（カード以外のリンクにも使うため）。今のロゴは黒で、これらはロゴの色ではなくサイトのテーマカラー
2. **テーマカラーを案2（空色）にする。使っている場所はすべて連動させる**
   - `primary-light`：#a0d8ef（伝統色「空色」）、`primary`：#4d9fd6
   - ライトのヒーローの背景：透明（3%）→ `primary-light` の 60%（50%）→ `primary` の 80%（100%）（今と同じ形で色だけ替わる）
   - Apps のアイコンの丸：`primary` の 70%（今と同じ形）
   - ライトのリンク `link`：#1e76ab（gray-100 の上で 4.51:1）。Markdown のページのリンクも `link`、ホバーは #005d91
   - ダークのリンク：`primary-light`（#a0d8ef。カードのホバー #333842 の上で 7.6:1）。Markdown のページのダークのリンクも同じ、ホバーは #a5def5
   - Markdown のページのリンクの色を、直書きの値ではなくトークン（`var(--color-…)`）で書く
3. **キャッチコピーの色**（トップのヒーロー「昼はカフェ。夜はバー。」）
   - ライトテーマのとき「昼」の1文字を #ce5a00、ダークテーマのとき「夜」の1文字を #e7d9a8 にする（もう一方のテーマでは色を付けない）
   - #ce5a00 は伝統色「黄丹」（#ee7800）を、案2のヒーローの背景に対して 3.3:1 まで暗くした色。#e7d9a8 は月をイメージした色
   - 色は飾り（意味は文字で伝わる）。見出しのテキストは「昼はカフェ。夜はバー。」のまま（読み上げも変わらない）。左の 0.5em の余白も保つ
   - 2色もトークンにする（例：`catch-day`、`catch-night`。名前は実装で決めてよい）
4. **DESIGN.md の「3. 色」を新しいトークンと値、理由に合わせて書き直す**（キャッチコピーの色の役割と、昼の色が背景に合わせて決めた値であることも書く）

## 受け入れ条件

- build、lint、format:check、`npm test`、`npm run test:e2e` が通る。仕様が変わった既存テストは合わせ、判断ログに一覧で書く
- `logo-` と `card-link` の名前がソースとビルドの出力に残っていない（テスト）
- 実際のブラウザで測ったコントラストのテスト（E2E）：
  - ライトの「昼」とヒーローの背景（文字の位置の実際の背景色）で 3:1 以上
  - ダークの「夜」とヒーローの背景で 3:1 以上
  - ライトのリンク（カード、Markdown）が白・gray-50・gray-100 の上で 4.5:1 以上、ホバーも
  - ダークのリンクが #282c34・#333842・#2e323b の上で 4.5:1 以上、ホバーも
  - 背景がグラデーションのところは、文字の位置の背景を計算するか、画面を撮って測る。どちらにしたかを判断ログに書く
- ライトでは「昼」だけ、ダークでは「夜」だけに色が付く（E2E）
- 幅 375px と 1280px、ライトとダークで崩れない
