## ユーザーの指示

1. **SVG Optimizer のダウンロードボタンのずれを直す。** ファイルを読み込んだあと、遅延読み込みの SVGO の最初のプレビューが出ると、プレビューの下のサイズの欄（約 126px）が増えてボタンが下にずれる（TS-10）。プレビューが出る前と後でボタンの位置が変わらないようにする（例：サイズの欄の場所を最初から確保しておく）。幅 375px と 1280px、日英で、ボタンの位置が変わらないことを E2E で確かめる
2. **クレジットのページから「必要に応じて素材名、著作者、ライセンス、参照先を記載します。」の段落を消す**
3. **カードの説明文を次のとおりにする**（`src/messages/ja.ts`）
   - SVG最適化：「ブラウザ上で完結するので安全です。」を消す →「品質を保ったままSVGのファイルサイズを削減し、Webサイトの読み込みを速くします。」
   - パスワードジェネレーター：「ブラウザ上で安全に作成できます」を消す →「文字数や文字の種類を選んで、強力なパスワードを生成。紛らわしい文字の除外にも対応しています。」（親の仮の文面）
   - tkinter-unblur：「Windows で Tkinter のアプリがぼやけて表示される問題をシンプルに解決する Python ライブラリです。」（ユーザー指定）
   - TWパレットジェネレーター：「50〜950の」を消す →「指定した色から、TailwindCSSに最適化されたカラーパレットを自動生成。統一感のある配色を作れます。」
   - ムルル：「ムルルに、ユーザーの声に合わせて自然に口が動くリップシンク機能とまばたき機能を追加するUnityツールです。」（ユーザー指定）
   - ほかのカードの説明文に「ブラウザ上で」の文言があれば同じく消し、判断ログに書く
4. **Libraries に `@i18n-tiny/react` を足す。** npm：`https://www.npmjs.com/package/@i18n-tiny/react`、ドキュメント：`https://docs.unlibra.com/i18n-tiny/react/introduction`（どちらも存在を確認済み）。並びは `@i18n-tiny/next` の次。画像は他の npm のライブラリと同じ。説明文は仮に「依存ゼロ・型安全・最小構成で、React のアプリを多言語化できる i18n ライブラリです。必要な機能だけを小さくまとめています。」（ほかの i18n-tiny と同じ形）。件数を数えているテストやサイトマップ、フッターなどがあれば合わせる
