## UR14-3 SVG最適化の名前（ユーザーの決定）

日本語の名前を「SVG最適化」から「SVGオプティマイザー」にした（Faviconジェネレーター、パスワードジェネレーターと形をそろえ、英語版の SVG Optimizer と対応させる）。ページのタイトルに検索語（「SVG圧縮・最適化」）は足さない。検索語は説明文（「無料のSVG最適化・圧縮ツール。…」）にあれば十分というユーザーの判断。変えたのはトップのカードのタイトルと、ツールの名前（見出し、パンくず、`<title>`）。テストの期待値（`portfolio.test.js`、`works.spec.js`）も合わせた。

## UR14-4 キャッチコピーの「昼」の色（ユーザーの決定）

`catch-day` を #ce5a00 から #d25f00 にした。ユーザーの希望は「下回らないぎりぎりの 3:1」。計算した背景（文字の下端あたり、#ceebf7）で 3:1 になる #d66200 は、実際の画面では文字の枠の上の方の背景（白に近い）に対して 2.89:1 だった。そこで、プレビューを幅 320、375、414、768、1024、1280、1440、1920px で撮り、見出しの文字を透明にして「昼」の枠の背景のピクセルをすべて集め、黄丹（#ee7800）を OKLab の明るさだけ下げて、すべてのピクセルに対して 3:1 以上になる最も明るい色を選んだ（#d25f00、最低 3.01:1）。`colors.spec.js` は 375px と 1280px で同じ測り方をして 3:1 以上を確かめる。
