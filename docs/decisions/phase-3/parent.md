# Phase 3 判断ログ（親）

## P3-1 トップページは1ページで、カテゴリごとのセクションにする

- 決めたこと：作品の詳細ページは作らない。トップページにカテゴリごとのセクションを並べ、カテゴリへはページ内リンクで移動する。旧ページのタブ切替（JS）はやめる
- 根拠：設計書に詳細ページの記載がない。作品数が十数件で1ページに収まる。JS なしで動き、Astro を選んだ利点（静的ページの JS を 0 にする）を保てる
- 他の選択肢：タブで絞り込む（旧ページと同じ）。作品ごとに詳細ページを作る
- 戻すときの作業：トップページのコンポーネントを直す

## P3-2 WEBツールの説明文とアイコンは liblab のものを流用する

- 決めたこと：ツールの名前と説明文は liblab の日本語メッセージ、画像は liblab のツールアイコンを使う
- 根拠：既存の文面と素材があり、新しく書くと画面の文言を新たに決めることになる
- 注意：ツールのアイコンをどちらのライセンス（MIT / All rights reserved）に入れるかは Phase 5 で決める
- 戻すときの作業：データと画像を差し替える

## P3-3 作品データのドキュメントリンクは説明文から分けて持つ

- 決めたこと：説明文の中に URL を書いて自動でリンクにする方式（旧 `linkify`）をやめ、作品データの項目としてドキュメントの URL を持つ
- 根拠：URL を差し替えるときに文章を触らずに済み、テストでも検査しやすい
- 戻すときの作業：説明文に URL を戻す
