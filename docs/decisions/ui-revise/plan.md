# UI の見直し（ユーザーの最終チェックの指示、2026-10-21）

## 背景

ユーザーがローカルのプレビューで UI を確かめ、liblab の UI とかけ離れていると指摘した。設計書 3.5 の「liblab のデザインをベースにする」を、親が色のトークンや部品の引き継ぎ程度に狭く読み、liblab の見た目の特徴（波形グラデーションのヒーロー、ヘッダーの構成、フッターの構成）を持ち込んでいなかった（Phase 2 の P2-1、Phase 4 の P4-3）。

## ユーザーの指示

1. **カード以外は liblab をほぼそのまま使う。** 移植元は `C:\Users\User\Projects\unlibra\liblab\frontend`（読むだけ）。対象：ヒーロー（`src/app/[locale]/(default)/page.tsx` の波形グラデーション、大きなロゴ、見出し、紹介文）、ヘッダー（`components/layout/header.tsx`、`category-popover.tsx`、`mobile-menu.tsx`、`language-switcher.tsx`、`theme-toggle.tsx`）、フッター（`components/layout/footer.tsx`）、配色・余白・フォントの扱い。ロゴは新しいシンボル（`src/assets/brand/symbol.svg`）とサイト名「unlibra.com」に置き換える
2. **ツール一覧ページ（`/lab`、`/en/lab`）は不要。** 削除する。4つのツールの個別ページ（`/lab/{tool}`、`/en/lab/{tool}`）は残す
3. **スポンサーボタン、X シェアボタン、シェアボタンを全ページで廃止する。** フッターの「寄付・支援」のリンクは残す（親の解釈。ユーザーの指示は「ボタン」）
4. **トップのカテゴリのボタン（自作キーボード、ソフトウェア、WEBツール、VRChat）を削除し、ヘッダーに移す。** liblab のヘッダーのカテゴリのポップオーバー（Toys / Tools）の位置と形を使い、トップの各カテゴリのセクションへのリンクにする。WEBツールのポップオーバーには4ツールの個別ページへのリンクも並べる（liblab と同じ）
5. **プロフィールの、スポンサーボタンの隣にある GitHub ボタンを削除する**
6. **フッターの TOOLS の列を削除し、同じ位置に「GitHub」「ドキュメント（https://docs.unlibra.com/）」「BOOTH ショップ（`site.links.booth`）」の3つのリンクを1つのグループとして置く。** グループの見出しは仮の文面にする
7. **著作権表示を `© 2025–{ビルドした年} unlibra` にする。** 終わりの年はビルド時の年。ビルドした年が 2025 のときは `© 2025 unlibra`

## 親の解釈と判断（この見直しの範囲）

- **ツール一覧ページの削除に伴う変更：**
  - ヘッダーの「ツール」へのリンクは、4の WEBツールのポップオーバーに置き換える
  - パンくずの起点「ツール / Tools」（一覧へのリンク）は、トップ（`/`）へのリンクにする。英語のツールページでは、トップは日本語のポートフォリオなので、起点の文言は仮の文面にする
  - `_redirects`：旧URL `/lab/ja`・`/lab/ja/` は `/#web`（トップの WEBツールのセクション。実際のアンカー名に合わせる）へ、`/lab/en`・`/lab/en/` も同じ所へ 301。新URL `/lab`・`/en/lab` も同じ所へ 301。各ツールの旧URLの転送は今のまま
  - サイトマップから一覧ページが消えること
- **トップのヒーロー：** liblab のヒーローの形（波形グラデーション、大きなロゴ、見出し、紹介文）を使い、中身をシンボル、「unlibra」、プロフィール文にする。今のプロフィールの部分（アバター、名前、文）はヒーローに統合してよい。アバターを残すかは見た目で判断し、判断ログに書く
- **作品カード：** 見せ方はユーザーが検討中。今のカードは見た目を変えずに残す（新しいレイアウトに収まるよう、位置と余白の調整だけはよい）
- 設計書 3.7 の著作権表示の記述（「年は固定」）は、親がこの見直しに合わせて直す

## 受け入れ条件

- K1：build、lint、format:check、`npm test`、`npm run test:e2e` が通る。既存のテストのうち、今回の指示で仕様が変わったもの（一覧ページ、ヘッダーの「ツール」リンク、パンくず、フッターの TOOLS、スポンサー・シェアのボタン、著作権表示、`_redirects`）は新しい仕様に合わせて直す。直したテストと理由は判断ログに一覧で書く。それ以外の既存テストは弱めない
- K2：上の1〜7が満たされていることを確かめるテスト（単体・E2E）がある
- K3：liblab と見比べた確認の記録を判断ログに残す。liblab の本番（`https://unlibra.com/lab/ja`、まだ旧サイト）と新サイトを、幅 375px と 1280px、ライトとダークで比べ、違いが残る箇所とその理由を書く
- K4：画面に出る新しい文言は、仮の文面として判断ログに一覧で書く
