# UI の見直し（12回目）：文字と余白の一貫性（ユーザー承認、2026-10-23）

## 参照する文書

- 文字の大きさと行の高さの規則：`docs/decisions/ui-revise7/plan.md` の 6（行の高さは DADS の倍率以上の 4 の倍数）
- 大カード：`src/components/works/FeaturedCard.astro`、`src/components/works/card-classes.ts`
- 見本（ユーザーが見て承認）：プレビューの `/mock-featured`（本番には入れない）

## 背景（親の実測）

- 大カードの見出しはスマホでも 36px で、ページの見出し（28px）とセクションの見出し（24px）より大きい
- スマホの大カードは、写真の左端が 16px、文字の左端が 24px（カードの p-4 と文字側の p-2 が重なる）。写真と文字の間は 24px
- ページの h1 が3通り：トップ 28px/600、ツール 24px/600、クレジットとプライバシー 32px/700
- 見出しの太さ：クレジットとプライバシーの h1・h2 が 700、ほかは 600。Favicon の形式の説明の `<strong>` が 700
- ツールの小見出し（画像を選択、プレビュー、出力オプションなど）が h6（h1 の次が h6）
- クレジットとプライバシーのページの余白（`max-w-3xl px-4 py-8`）が、ほかのページ（`px-4 sm:px-6 lg:px-8`、`pt-8 pb-12`）と違う

## ユーザーの指示（承認された案）

1. **大カードの見出し：** 幅 768px 未満（大カードが縦に積まれる幅）で 24px・行の高さ 36px（セクションの見出しと同じ）。768px 以上は 36px・52px のまま。太さは 600 のまま
2. **大カードのスマホの余白：** 768px 未満で、文字の左端を写真の左端にそろえる（文字側の内側の余白をなくす）。写真と文字の間を 24px → 16px。768px 以上の見た目は変えない
3. **ページの見出し（h1）をすべて 28px・行の高さ 44px・600 にそろえる：** ツールのページ（24px → 28px）、クレジットとプライバシー（32px/700 → 28px/600）。トップのヒーローは今のまま（28px/600）
4. **見出しの太さを 600 にそろえる：** Markdown のページの h1・h2 を 600 に。Favicon の形式の説明の `<strong>` を 600 に（`font-semibold`）。700 はロゴタイプ「unlibra」だけ
5. **ツールの小見出しを h6 から h2 にする**（見た目は変えない：16px/24px/600）。見出しの順が飛ばないこと。Headless UI の DisclosureButton の中の見出しも同じ
6. **クレジットとプライバシーのページの余白を、ほかのページと同じにする：** 左右 `px-4 sm:px-6 lg:px-8`、上下 `pt-8 pb-12`。本文の幅 `max-w-3xl` は保つ
7. ヒーローの GitHub と BOOTH の太さ（600）は今のまま（ユーザー承認）
