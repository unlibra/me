## 親の解釈と判断

- 背景：画面全体を `#282c34` にし、星を画面全体に散らして広げる（SVG の 100×100 の枠の中だけに星がある状態にしない）。星の見た目（`star-small`、`star-faint`）とまたたきは元の SVG に合わせる
- 惑星：画面の中央。大きさは画面の短い辺を基準にして（目安は 40〜50%）、幅 375px でも 1280px でも、文字とボタンと一緒に1画面に収まること
- テキスト：「ページが見つかりません」。ボタン：カプセル型（`rounded-full`）の「トップに戻る」、リンク先は `/`。英語は出さない（ユーザーの指定どおり日本語のみ。今の日英併記をやめる）
- ヘッダーとフッターは出さない（全画面の宇宙を見せるため）。ライトモードでも暗いまま
- 元の SVG のアニメーションと `prefers-reduced-motion` の扱いを保つ。SVG のメタデータ（DiceBear、CC0）は残す
- `<title>`、`noindex`、404 のステータス（`not_found_handling`）は今のまま
- ライセンス：DiceBear の CC0 素材として、LICENSE の第2節の DiceBear の項に、置いたファイルを足す（license のテストの出典の検査も通ること）
