# 404 ページのデザイン変更の判断ログ（not-found）

計画：`not-found/plan.md`。ここには、計画とユーザーの指示に書かれていない判断を書く。

## NF-1 素材：元の SVG を2つに分けて置いた

- 決めたこと：元の SVG（`%TEMP%\claude\inbox\planets.svg`）から、次の2つのファイルを作って `src/assets/not-found/` に置いた。どちらも、取り除いた部分のほかは元のまま（`width="512" height="512"` は外した）。DiceBear の生成コメントとメタデータ（DiceBear、CC0）は残し、何を除いたかのコメントを足した
  - `planet.svg`：惑星（円盤、地表、陰、環、衛星2つ）とアニメーション（`<style>`、`prefers-reduced-motion: no-preference` のときだけ動く）。背景の `rect` と星 12個（定義と `<use>`）を除いた
  - `stars.svg`：背景の `rect`（`#282c34`）と星 12個。惑星とアニメーションの定義と `<use>` を除いた
- ページでは、惑星を CSS のアニメーションが効くようにインラインで出し（`?raw` と `set:html`）、星を `main` の背景のタイルにした。タイルの大きさは惑星の箱（元の 100×100）と同じで、どちらも画面の中央に置くので、惑星のまわりの星は元の SVG と同じ並びになり、その外は同じ並びが繰り返される
- LICENSE 第2節の DiceBear の項に2つのファイルを足し、見出しを `DiceBear "Shapes" and "Planets"` にした
- 他の選択肢：画面全体に別の乱数で星を散らす（元の SVG にない星になる）。元の SVG を `<img>` で中央に置き、背景だけ `#282c34` にする（星が中央の正方形にしかない）
- 戻すときの作業：`src/assets/not-found/` と LICENSE の2行を消す

## NF-2 星のまたたき：元の SVG のとおり、またたかない

- 見つけたこと：元の SVG の `<style>` には、またたきの CSS（`.dbpa-tw-medium`・`.dbpa-tw-large`・`.dbpa-tw-sparkle`）があるが、どの星にもそのクラスが付いていない。元の SVG を開いても、動くのは地表と衛星の回転だけで、星はまたたかない
- 決めたこと：計画の「星の見た目とまたたきは元の SVG に合わせる」に従い、星は動かさない（元のまま）。またたきの CSS は `planet.svg` の `<style>` に元のまま残っている（使われない）
- 他の選択肢：星にまたたきのクラスを付けて、またたかせる（元の SVG にない動きになる）。**計画の前提（「星のまたたきのアニメーション」がある）と違うので、親に確認してほしい**
- 戻すときの作業：またたかせるなら、`stars.svg` の星の `<use>` にクラスを付け、またたきの CSS を `stars.svg` にも入れる（背景の画像の中の CSS アニメーションは動く）

## NF-3 惑星の大きさと置き方

- 決めたこと：惑星の箱（元の 100×100）を `min(50vmin, 100dvh - 20rem)` にし、画面の中央に置いた。環を含めた惑星は箱の約 92%、円盤は約 60% なので、環を含めて短い辺の約 46%（計画の目安 40〜50%）になる。見出しとボタンは箱の真下に置いた（惑星が画面の中央からずれないよう、`absolute` で箱の下につなげた）。`100dvh - 20rem` は、高さの低い画面（横向きのスマートフォンなど）で見出しとボタンが画面の外に出ないための上限
- 確かめたこと：幅 375px（高さ 667px）と 1280px（高さ 800px）で、惑星が中央にあり、見出し・ボタンと重ならず、全部が1画面に収まること（E2E と、撮った画面）
- 戻すときの作業：`404.astro` の `--planet` を変える

## NF-4 ヘッダーとフッターをなくす方法、テーマ、`<title>`

- 決めたこと：
  - `BaseLayout` に `bare` を足し、付けたページではヘッダーとフッター（とその外側の枠）を出さず、中身だけを出す。404 だけが使う。`<head>`（テーマの初期化、メタデータ、アイコン）は今までどおり
  - ライトでも暗いまま：背景と文字の色を `dark:` を使わずに直接指定した（背景 `atom-one-dark`＝`#282c34`、文字は白、ボタンは白地に `#282c34` の文字）
  - `<title>`（「ページが見つかりません / Page not found - unlibra」）と description は、計画の「今のまま」に従い英語を残した。画面に出る文字は日本語だけ
  - `noindex`：今の 404 ページには `noindex` の meta はなく（404 のステータスで検索に載らない）、計画の「今のまま」に従って足していない
- 戻すときの作業：`BaseLayout` の `bare` を消し、`404.astro` を前の形に戻す
