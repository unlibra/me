# 寄付ページの判断ログ

親が直接実装した寄付ページの追加（2026-10-24、ユーザーの指示）。レビューは省き、親が build、lint、format:check、`npm test`、`npm run test:e2e` で確かめた。

## DN-1 フッターの寄付リンク（ユーザーの決定）

フッターの「寄付・支援」は OFUSE（`https://ofuse.me/unlibra`）ではなく、サイト内の `/donate` に飛ぶ。サイト内のページなので同じタブで開く。OFUSE へのリンクはサイトからなくした（`site.links.sponsor` を消した）。英語のページのラベルは、ほかの日本語だけのページと同じく「Donate & Support (Japanese)」にした。

## DN-2 寄付の受け取り方（ユーザーの決定）

寄付は Amazon eギフトカードで受け取る。受取人のアドレスは `gift@unlibra.com`。リンクのボタンは amazon.co.jp の Amazon eギフトカードの商品ページ（`/dp/B06X1GVMW7`）に飛ぶ。ユーザーが選んだのは「Eメールタイプ」で、Amazon での今の名前が「Amazon eギフトカード」なので、ページの文言もそちらにした（2026-10-24 に商品ページで確かめた）。値は `src/config/site.ts` の `site.donation` に置いた。

商品ページはユーザーの指定で、デザイン「Amazon スマイル」の `B06X1GVMW7`（初めは「Amazonロゴ - クラシック」の `B004N3APGO` だった）。

リンクには `?gpo=500` を付け、Amazon のページで金額に ¥500 が入った状態で開く。`gpo` はユーザーが示したパラメータで、2026-10-24 に `B06X1GVMW7` の商品ページの金額の欄が ¥500 になることを確かめた。金額は Amazon のページで変えられるので、ページの「金額は自由です」はそのままにした。

初期値の ¥500 は、ユーザーの「日本で最も一般的な寄付金額に合わせる」という指示による。1回の寄付の金額の分布を直接示す統計は見つからなかった。近い調査の中で、1回の少額の応援として最も多かったのが「500円以下」（消費者庁のコラム。ライブ配信の投げ銭で、2018年の調査）だったので ¥500 にした。寄付白書の中央値の1万円は、1年間の寄付の合計なので使わなかった。

## DN-3 ページの作り

- 日本語だけのページで、クレジット・プライバシーポリシーと同じ `MarkdownLayout`。h1「寄付・支援」、案内の段落、アドレスとコピーのボタン、Amazon のボタンの順。
- アドレスは等幅（16px / 24px）で、カードと同じ面（gray-50、ダークは `atom-one-dark-light`、角丸 `rounded-card`）に置く。
- コピーのボタンは、見えている文字「コピー」がそのまま読み上げの名前になる（`aria-label` は付けない）。結果（「コピーしました」か、失敗したときの案内）は `role="status"` の段落に出して読み上げに伝える。React は使わず、ページの小さなスクリプトで動かす。
- Amazon のボタンは新しいタブで開くリンク。色はライトが `link` の地に白（5.0:1）、ダークが `primary-light` の地に gray-900。Markdown のページのリンクの色（下線つき）を当てないよう、`MarkdownLayout` のリンクの規則を `a:not([data-button])` にした。
- 色の変化の動きは `motion-safe:` にし、動きを減らす設定では止める（DESIGN.md 5.6）。
- アイコンは既存の `ArrowUpRightIcon` だけを使い、新しいアイコンは足していない。

## DN-4 テスト

- `tests/donate.test.js`：設定の値、アドレスとコピーのボタン、Amazon のリンク、canonical とサイトマップ、OFUSE へのリンクがどのページにもないこと。
- `tests/e2e/donate.spec.js`：コピーでアドレスがクリップボードに入って「コピーしました」と出ること、ボタンの文字と地の色の比が両方のテーマで、ホバーの前後とも 4.5:1 以上であること。
- 既存のテストのページの一覧（ビルドのページ、サイトマップ、日本語だけのページ、Markdown のページの余白と文字）に `/donate` を足し、フッターのリンクの期待値を `/donate` にした。
- 「ドメインを文字として出さない」テスト（ui-revise2 4）は、寄付ページのアドレス `gift@unlibra.com` だけを除いた。
