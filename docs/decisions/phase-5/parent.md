# Phase 5 判断ログ（親）

## P5-1 ツールのアイコンは、ユーザーが決めるまで All rights reserved 側に置く

- 決めたこと：`src/assets/tools/` のツールのアイコン（liblab から持ってきたもの）は MIT の範囲に入れず、All rights reserved のままにする。どちらにするかをユーザーに確認する
- 根拠：設計書 3.7 が MIT にすると決めたのは「WEBツールの実装コード」と「UI部品」で、アイコンのような画像素材は含まれていない。ライセンスを狭いほう（All rights reserved）にしておけば、あとで MIT に広げるのは簡単だが、一度 MIT で公開したものを戻すことはできない
- 他の選択肢：ツールの一部として MIT にする
- 戻すときの作業：アイコンを `src/tools/` 以下に移し、`LICENSE` の記述を直す

## P5-2 `LICENSE` は英語で書く

- 決めたこと：`LICENSE` の本文は英語にする
- 根拠：GitHub 上で読まれる前提の文書で、MIT の原文も英語。日本語訳を併記すると、どちらが正本かという問題が生じる
- 他の選択肢：日英併記
- 戻すときの作業：日本語の節を足す
