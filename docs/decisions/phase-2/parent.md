# Phase 2 判断ログ（親）

ユーザーは「UIデザインは最後にまとめてチェックする」と言っている（2026-10-21）。ここに書いた仮の方針は、そのチェックで変わる前提で決めている。

## P2-1 ヘッダーの構成

- 決めたこと：左にロゴシンボルとサイト名「unlibra.com」。右に「ツール」へのリンク、GitHub へのアイコンリンク、テーマ切替。言語切替は別言語版のあるページだけ。ハンバーガーメニューは作らない
- 根拠：サイト名は現行 me のヘッダーと同じ表記を仮に使う（新サイトでの表記はユーザーが未定としている）。liblab にあったカテゴリのポップオーバーは、ツールが4つだけになったので要らない
- 他の選択肢：サイト名を「unlibra」にする。作品カテゴリへのリンクを並べる
- 戻すときの作業：ヘッダーのコンポーネント1つと文言を直す

## P2-2 フッターの構成

- 決めたこと：ロゴとサイト名、説明文、GitHub・支援（ofuse）・プライバシーポリシーへのリンク、「© 2025 unlibra」。liblab にあった「バグ報告」「問い合わせ」は外す
- 根拠：「バグ報告」「問い合わせ」は liblab リポジトリの Issues と Discussions へのリンクだった。liblab はアーカイブするので、行き先がなくなる
- 他の選択肢：me リポジトリの Issues を受け口にする
- 戻すときの作業：フッターにリンクを足す

## P2-3 色は liblab のトークンをそのまま使う

- 決めたこと：liblab の `atom-one-dark` と `logo`（水色・青・オレンジ）を移す
- 根拠：設計書 3.5 で liblab のデザインをベースにすると決めている。ただし `logo` の色は旧 Lib Lab ロゴの色で、新しいシンボル（濃いグレーと白）とは合っていない。UIチェックで見直す候補として残す
- 戻すときの作業：`global.css` のトークンを差し替える

## P2-4 テーマ切替は React を使わずに作る

- 決めたこと：テーマ切替は Astro コンポーネントと素の JS で作る。liblab の `next-themes` と headlessui は使わない
- 根拠：ポートフォリオのページは操作できる部分がほぼなく、テーマ切替のためだけに React を読み込むと、Astro を選んだ利点（静的ページの JS を 0 にする）が失われる
- 他の選択肢：React の island として作り、全ページで React を読み込む
- 戻すときの作業：コンポーネント1つを書き直す
