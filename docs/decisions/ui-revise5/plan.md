## 本番（ブランチ `feat/site-replacement`）に入れるもの

1. **ヒーローのボタンはパターン A（ロゴ＋テキスト）にする。** GitHub は公式のマーク（見本ブランチの `GitHubIcon.astro` と LICENSE・テストの変更を持ってくる）。BOOTH のアイコンは、ユーザーが見本で選ぶまで仮に Lucide の `shopping-bag` にする（Lucide は ISC ライセンス。LICENSE 第2節に第三者のコードとして載せ、全文を `LICENSES/` に置く。npm パッケージから写す場合は版を固定し、出典のコメントを付ける）
2. **リンクのカードで、タイトルの横の ↗ を付けない**
3. **DIY Keyboards のセクション全体を 24px 下げ、ヒーローの波との間を空ける**
4. **404 ページの中身を全体的に上へ寄せる**（今は下に寄りすぎている）。縦積みの画面で、惑星と文字のまとまりを今より上に置く。これまでの 404 のテスト（重ならない、横スクロールなし、惑星の大きさ、各画面サイズ）はすべて通ること
5. **VR & 3D のカードに「BOOTH で見る」と「ドキュメント」のテキストリンクを付ける。** ムルル対応ツールのドキュメントは `https://docs.unlibra.com/mururu-blink-lipsync/`
6. **Apps のアイコンを丸にする**
7. **Libraries のアイコンの枠（ボーダー）を消す。** Apps にも枠があれば消す
8. **リンクの矢印アイコンを小さくする。** テキストと同じ大きさ（14px）にし、テキストと上下中央で揃える
9. **Apps に「アプリを開く」のリンクを付ける**（今の「ツールを使う」を置き換える。カードと詳細で文言を揃える規則は続ける）
10. **Libraries の1番目（主）のリンクを npm または PyPI にする。** 2番目がドキュメント
11. **カードのクリックは、どのカードでも1番目のリンクを開くことに統一する。** ホバーしたとき、1番目のリンクに下線を付ける。1番目は：Apps「アプリを開く」、Libraries「npm / PyPI」、VR & 3D「BOOTH で見る」。DIY Keyboards はリンク先がないので、1番目は「詳しく見る」（詳細を開く）のまま
12. **DIY Keyboards と VR & 3D のカードの枠線（ボーダー）を消す**
13. **大サイズのカード：見出しを `text-4xl` にし、見出しの上（以前に年があった位置）に「SPOTLIGHT」のサブタイトルを置く。** カードのデザインそのものは、14 の見本でユーザーが選ぶまで今のまま（ただし 12 で枠線が消えるなら、大サイズのカードも見本の「今の形」との対応が分かるようにする）

## 見本（ローカルブランチ、本番には入れない）

プレビュー用の worktree で、本番の作業をコミットしたあとの最新から作るローカルブランチ `mock/ui-revise5` に、見本ページを2つ作る（noindex、サイトマップから除外）。

- **`/mock/booth-icons`（指示1）：** GitHub のロゴとテキストのボタンの隣に、BOOTH のボタンを Lucide の4種のアイコン（`handbag`、`shopping-bag`、`package`、`box`）で並べて比べる。ヒーローの実際の大きさと配色で、ライト・ダーク両方
- **`/mock/featured-cards`（指示14）：** 大サイズのカードのデザインを5案並べる。
  - 1：今のまま（枠線あり。12 の変更前の形）
  - 2：枠線なしで、背景に網掛け（細い斜線などの模様）
  - 3〜5：開発者が考える新しい3案（例：写真を全面に敷いて文字を重ねる、淡い色の面で区切る、写真と文字の面をずらして重ねる など）。各案に短い説明を付ける
  - どの案も、見出し 4xl と「SPOTLIGHT」、1番目のリンクへの下線のホバーは本番と同じにする

## 受け入れ条件

- P1：build、lint、format:check、`npm test`、`npm run test:e2e` が通る（本番）。仕様が変わった既存テストは新しい仕様に合わせ、判断ログに一覧で書く。それ以外は弱めない
- P2：1〜13 のそれぞれを確かめるテストがある（矢印の大きさと上下中央、1番目のリンクがカードのクリックの行き先でありホバーで下線が付くこと、枠線がないこと、404 のまとまりの位置が今より上であることを含む）
- P3：ライトとダーク、幅 375px と 1280px で崩れない
- P4：見本ページ2つを、プレビュー用の worktree でビルドして見られる状態にする（ポート 8790 は親のプレビューサーバー。ビルドしてよいが、サーバーは止めない）
- P5：新しい文言（「アプリを開く」「SPOTLIGHT」など）を、仮の文面として判断ログに書く
